API-CONTRACT-012 — Sync API

Version : V1

Statut : MVP

1. Mission

La Sync API est responsable de la synchronisation des données entre les clients (Web, Mobile) et les

services distants de Vitala.

Elle met en œuvre la stratégie Offline First de la plateforme.

Son rôle est d'assurer que les actions effectuées hors connexion soient synchronisées de manière fiable

dès que la connectivité est rétablie.

Elle ne possède jamais les données métier.

6. Règles métier (Business Rules)

•

Les opérations sont exécutées dans leur ordre de création.

•

Les domaines restent propriétaires de leurs données.

•

La Sync API ne modifie jamais les règles métier.

•

Les conflits sont résolus selon les politiques définies par chaque domaine.

•

Toutes les synchronisations sont traçables.

8. Validation

•

•

•

9. Sécurité

Toutes les synchronisations sont :

•

authentifiées ;

•

chiffrées ;

•

journalisées.

Les données sensibles restent protégées pendant tout le processus.

10. Dépendances

La Sync API dépend :

•

Auth API ;

•

Unified Digital Identity API ;

•

Supabase ;

•

l'ensemble des domaines métier.

Elle ne devient jamais propriétaire des données synchronisées.
