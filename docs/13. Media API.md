API-CONTRACT-010 — Media API

Version : V1

Statut : MVP

1. Mission

La Media API est responsable de la gestion des ressources multimédias de Vitala.

Elle fournit un service unifié pour le téléversement, le stockage, la consultation, la mise à jour et la

suppression des médias (images, vidéos, documents, fichiers audio et autres pièces jointes).

Elle ne possède jamais les objets métier qui utilisent ces médias.

6. Règles métier

•

Un média appartient à son propriétaire.

•

Les domaines stockent uniquement une référence vers le média.

•

La suppression d'un média suit les règles de sécurité et de conservation.

•

Les médias privés ne sont accessibles qu'aux utilisateurs autorisés.
