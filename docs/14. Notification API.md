API-CONTRACT-011 — Notification API

Version : V1

Statut : MVP

1. Mission

La Notification API centralise toutes les notifications de Vitala.

Elle distribue les événements importants produits par les domaines métier vers les utilisateurs

concernés.

Elle ne décide jamais quelles notifications doivent être créées.

Les domaines métier publient des événements, la Notification API les distribue.

6. Règles métier

•

Une notification est produite à partir d'un événement métier.

•

Une notification ne modifie jamais les données métier.

•

Les préférences utilisateur déterminent le mode de diffusion.

•

Les notifications importantes peuvent être prioritaires.
