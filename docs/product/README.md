## Règles de maintenance

- Les modifications actives doivent viser les références produit actives, pas les anciennes versions numérotées.
- Un persona décrit un contexte d'intention ; il ne définit ni une identité permanente ni une permission d'accès.
- Un parcours décrit une intention et des états attendus ; il ne prouve pas que le parcours est implémenté.
- Les niveaux et vues de confiance documentés doivent être distingués de leur implémentation vérifiée.
- Les sources historiques ne sont ni supprimées ni déplacées dans le cadre de ce classement. Toute déduplication ou migration ultérieure exige une comparaison de contenu, la vérification des liens entrants et une validation explicite.
