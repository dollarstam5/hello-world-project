# 1. Objectif

Permettre à un utilisateur de manifester son intérêt pour une opportunité de manière simple, rapide et sans créer de surcharge pour l'auteur. Vitala privilégie l'intention et la pertinence plutôt que la compétition.

# 2. Philosophie

Vitala n'utilise pas le modèle classique :

- candidature complexe;
- CV obligatoire;
- messagerie ouverte;
- commentaires publics.
L'objectif est de permettre une expression d'intérêt claire et contrôlée.

# 3. Définition

Répondre à une opportunité signifie :

Manifester son intérêt pour participer, aider, collaborer, proposer un service, fournir une ressource ou répondre à un besoin publié dans Vitala.

# 4. Conditions préalables

Statut minimum : Membre enregistré L'opportunité doit être :

- Active
- Visible pour l'utilisateur
- Encore ouverte aux réponses
# 5. Déclenchement

L'utilisateur consulte une opportunité. Exemple : Recherche d'une ménagère demain matin à Bonanjo. Il choisit :

- Je suis intéressé
- Je suis disponible
- Je peux aider
- Répondre
Selon le contexte de l'opportunité.

# 6. Réponse minimale

La réponse peut être extrêmement simple. Exemple : Je suis intéressé. ou Je suis disponible.

# 7. Message complémentaire

L'utilisateur peut ajouter un message facultatif. Exemple : Disponible demain dès 8h. ou J'ai déjà réalisé ce type de mission. ou Je peux intervenir rapidement.

# 8. Informations automatiques transmises

Lorsqu'une réponse est envoyée, Vitala transmet automatiquement :

- Profil utilisateur
- Niveau de confiance
- Statuts visibles
- Localisation utile
- Historique pertinent
- Disponibilité éventuelle
- Métadonnées système
Aucun document supplémentaire n'est exigé.

# 9. Contrôle de capacité

Chaque opportunité possède un nombre maximal de réponses. Exemple : Maximum : 5 réponses Lorsque la limite est atteinte : L'opportunité cesse d'accepter de nouvelles réponses.

# 10. Fermeture automatique

Après atteinte du seuil : Statut : Réponses complètes ou Sélection en cours Selon le contexte.

# 11. Confidentialité

Les répondants ne voient jamais :

- Le nombre exact de concurrents
- Les autres répondants
- Les profils des autres répondants
- Les échanges internes
Chaque réponse reste privée.

# 12. Contrôle qualité

Avant validation : Safety & Trust Filter Engine analyse :

- Spam
- Fraude
- Réponses abusives
- Contenus interdits
- Comportements suspects
# 13. Réception côté auteur

L'auteur reçoit :

- Les profils intéressés
- Les informations utiles

- Les statuts de confiance
- Les éléments de crédibilité disponibles
Présentation recommandée : Référencé Vérifié Confirmé Recommandé Actif Fiable

# 14. Décision de l'auteur

L'auteur reste libre de :

- Accepter
- Refuser
- Ignorer
- Reporter
une réponse. Aucune sélection automatique n'est imposée.

# 15. Notification des répondants

Les répondants sont informés :

- Réponse reçue
- Réponse consultée
- Réponse retenue
- Réponse non retenue
Les messages restent simples et respectueux.

# 16. Mise en relation

La mise en relation n'est créée qu'après sélection.

Avant la sélection : Aucun canal direct n'est ouvert.

# 17. Création du canal contextuel

Après sélection : Vitala ouvre un espace d'échange limité à l'opportunité concernée. Exemple : Mission ménagère du 12 juillet. L'échange reste lié à cette action.

# 18. Limites de la messagerie

La messagerie Vitala n'est pas conçue comme :

- WhatsApp
- Messenger
- Telegram
- Réseau social classique
Elle sert uniquement à faciliter l'exécution de l'opportunité.

# 19. Échec de sélection

Si l'utilisateur n'est pas retenu : Notification : Merci pour votre intérêt. Cette opportunité a déjà trouvé une solution.

# 20. Passage à l'action

Une fois la sélection effectuée : Réponse

↓ Sélection ↓ Notification ↓ Mise en relation ↓ Action

# 21. Principes UX

## Principe 1

Répondre doit prendre quelques secondes.

## Principe 2

Aucune candidature complexe.

## Principe 3

Aucune concurrence visible.

## Principe 4

Respect de la confidentialité.

## Principe 5

L'auteur garde le contrôle.

## Principe 6

La mise en relation intervient uniquement lorsqu'elle devient utile.

# 22. Critère de réussite

Le parcours est réussi lorsque : Utilisateur ↓ Découvre une opportunité ↓ Manifeste son intérêt ↓ Réponse enregistrée ↓ Auteur sélectionne ↓ Mise en relation créée ↓ Action réalisée sans surcharge, sans compétition inutile et sans messagerie ouverte prématurément.
