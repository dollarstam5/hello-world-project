# Annexe commune aux User Journeys (04 à 13)

## Intégration de l'Unified Digital Identity (UDI)

Cette section s'applique à l'ensemble des User Journeys de Vitala.

# 1. Principe général

Dans tous les parcours utilisateurs, le terme **profil** désigne désormais la représentation fonctionnelle de l'**Unified Digital Identity (UDI)**. L'UDI constitue l'identité numérique officielle de chaque utilisateur au sein de la plateforme. Elle est alimentée par les différents domaines métier sans jamais devenir propriétaire de leurs données.

# 2. Évolution de l'identité

Chaque action réalisée au cours d'un User Journey peut contribuer à l'évolution de l'UDI. Exemples :

- publication d'un Flash;
- participation à une mission;
- validation d'une action;
- interaction avec la communauté;
- création d'une opportunité;
- réponse à une opportunité.
Ces actions enrichissent progressivement l'identité numérique de l'utilisateur.

# 3. Les moteurs métier

Les moteurs spécialisés (Trust Engine, Radar Engine, Veille Engine, Recommendation Engine, etc.) analysent les événements produits par les User Journeys. Ils restent entièrement indépendants des parcours utilisateurs. Leurs résultats sont publiés sous forme de **Views** intégrées à l'UDI.

# 4. Les Views

Les informations présentées à l'utilisateur dans son espace personnel sont issues de projections métier. Parmi celles-ci :

- Trust View;
- Activity View;
- Radar View;
- Veille View;
- Recommendation View.
Ces vues représentent les résultats des domaines métier. Elles ne contiennent aucune logique de calcul.

# 5. Responsabilités

Les User Journeys décrivent uniquement les interactions métier. Ils ne réalisent jamais directement :

- le calcul du Trust;
- la génération des recommandations;
- la détection Radar;
- l'analyse Veille.
Ces responsabilités appartiennent exclusivement aux moteurs spécialisés.

# 6. Principe de cohérence

Toutes les informations visibles par l'utilisateur proviennent d'une unique source de vérité. Chaque domaine métier reste propriétaire de ses données. L'UDI construit une représentation cohérente destinée aux interfaces utilisateur.

# 7. Compatibilité

Cette évolution ne modifie pas la logique métier des User Journeys. Elle renforce uniquement la cohérence de l'architecture en intégrant le concept d'Unified Digital Identity comme représentation officielle de l'utilisateur dans l'ensemble des parcours de Vitala.
