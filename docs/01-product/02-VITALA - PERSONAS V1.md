# VITALA-PERSONAS V1

**Document ID :** VITALA-PERSONAS-V1 **Version :** 1.0 **Statut : VALIDÉ** **Dépendance :** VITALA-VISION-V1

# 1. Introduction

Les personas Vitala ne représentent pas des catégories sociales, des métiers ou des groupes démographiques. Ils représentent des comportements observés dans la plateforme. Une même personne peut adopter plusieurs personas selon le contexte, ses besoins, ses opportunités ou ses actions. Exemple : Une mère de famille peut être :

- Découvreuse le matin.
- Demandeuse à midi.
- Recommandeuse le soir.
Vitala s'intéresse principalement à ce que l'utilisateur cherche à accomplir à un instant donné.

# 2. Principe Fondamental

Vitala ne cherche pas d'abord à savoir : "Qui êtes-vous ?" Vitala cherche à comprendre : "Que souhaitez-vous faire maintenant ?" Les personas décrivent donc les intentions et comportements réels des utilisateurs.

# 3. Personas MVP

Les personas suivants sont indispensables au fonctionnement du MVP.

# Persona 1 : Consultant

## Description

Le consultant découvre Vitala pour la première fois. Il n'est pas encore engagé dans la plateforme. Il souhaite comprendre ce que Vitala peut lui apporter.

## Objectifs

- Découvrir l'application.
- Comprendre son utilité.
- Observer sans engagement.
- Explorer les possibilités.
## Motivations

- Curiosité.
- Recherche d'opportunités.
- Découverte.
## Actions principales

- Consulter la Home.
- Explorer les fonctionnalités.
- Visualiser les opportunités publiques.
- Découvrir les avantages de Vitala.
## Niveau de confiance

Inconnu.

## Évolution possible

Consultant ↓

Découvreur

# Persona 2 : Découvreur

## Description

Le découvreur cherche à trouver quelque chose d'utile. Il commence à interagir avec Vitala.

## Objectifs

- Trouver des opportunités.
- Explorer son environnement.
- Découvrir des solutions.
## Motivations

- Gagner du temps.
- Trouver rapidement des réponses.
- Identifier des ressources utiles.
## Actions principales

- Utiliser Radar.
- Utiliser Flash.
- Consulter les recommandations.
- Sauvegarder des opportunités.
## Opportunités recherchées

- Services.
- Recommandations.
- Informations.
- Opportunités locales.
## Évolution possible

Découvreur

↓ Demandeur ou ↓ Contributeur

# Persona 3 : Demandeur

## Description

Le demandeur cherche une solution à un besoin précis.

## Objectifs

- Résoudre un problème.
- Trouver une personne.
- Trouver une ressource.
- Trouver une information.
## Motivations

- Besoin immédiat.
- Besoin planifié.
- Recherche d'efficacité.
## Actions principales

- Publier un Flash.
- Créer une opportunité.
- Lancer une recherche Radar.
- Sélectionner des candidats.
## Exemples

- Recherche d'une ménagère.
- Recherche d'une cuisinière.
- Recherche d'un artisan.
- Recherche d'un chauffeur.

- Recherche d'un partenaire.
## Niveau de confiance attendu

Membre enregistré minimum.

## Évolution possible

Demandeur ↓ Recommandeur

# Persona 4 : Contributeur

## Description

Le contributeur apporte une solution.

## Objectifs

- Mettre ses compétences à disposition.
- Valoriser ses ressources.
- Répondre aux opportunités.
## Motivations

- Générer un revenu.
- Aider.
- Développer sa réputation.
- Se faire connaître.
## Actions principales

- Répondre à une opportunité.
- Proposer un service.
- Proposer une ressource.
- Partager une information utile.

## Exemples

- Femme de ménage.
- Cuisinière.
- Maçon.
- Artisan.
- Enseignant.
- Prestataire.
## Niveau de confiance attendu

Identifié recommandé.

## Évolution possible

Contributeur ↓ Recommandeur ↓ Professionnel

# Persona 5 : Recommandeur

## Description

Le recommandeur partage sa confiance. Il contribue à renforcer la qualité de l'écosystème Vitala.

## Objectifs

- Aider les autres.
- Mettre en avant des personnes fiables.
- Partager son expérience.

## Motivations

- Confiance.
- Entraide.
- Réputation.
## Actions principales

- Recommander une personne.
- Recommander une organisation.
- Valider une expérience réussie.
- Partager une référence.
## Exemples

- Recommander un voisin.
- Recommander un professionnel.
- Recommander une association.
- Recommander un prestataire.
## Niveau de confiance attendu

Utilisateur vérifié minimum.

## Évolution possible

Recommandeur ↓ Garant

# 4. Personas Évolués

Ces personas apparaîtront dans les versions ultérieures de Vitala.

# Persona 6 : Garant

Apporte une garantie morale, sociale ou professionnelle.

Exemples :

- Employeur.
- Responsable.
- Association.
- Organisation.
- Référence reconnue.
# Persona 7 : Acteur Local

Anime et mobilise un environnement local. Exemples :

- Coordinateur.
- Responsable de groupe.
- Leader local.
- Organisateur.
# Persona 8 : Professionnel

Utilise Vitala pour développer durablement une activité. Exemples :

- Artisan.
- Entrepreneur.
- Prestataire.
- Entreprise.
# 5. Profils de Contexte

Les profils de contexte ne sont pas des personas. Ils servent à personnaliser l'expérience utilisateur. Exemples :

- Parent.
- Jeune.
- Étudiant.
- Famille.
- Retraité.
- Professionnel.

- Artisan.
- Association.
- Entreprise.
- Organisation.
Un utilisateur peut posséder plusieurs profils de contexte simultanément.

# 6. Cycle Naturel d'Évolution

Le parcours habituel dans Vitala est : Consultant ↓ Découvreur ↓ Demandeur ou ↓ Contributeur ↓ Recommandeur ↓ Garant ↓ Professionnel

# 7. Conclusion

Les personas Vitala décrivent les comportements observés dans la plateforme. Ils permettent de comprendre les intentions des utilisateurs afin de proposer des expériences, opportunités et recommandations adaptées à chaque étape de leur évolution.

Les personas ne sont pas figés. Ils évoluent continuellement selon les actions réalisées dans l'écosystème Vitala.
