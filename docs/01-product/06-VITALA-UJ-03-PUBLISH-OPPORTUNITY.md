# 1. Objectif

Permettre à un utilisateur de transformer rapidement un besoin, une offre, une recherche, une idée ou une intention en opportunité exploitable par l'écosystème Vitala. La création d'une opportunité doit être simple, naturelle et guidée. L'utilisateur ne doit jamais avoir l'impression de remplir une annonce complexe.

# 2. Définition officielle

Une opportunité est toute intention, besoin, offre, demande, projet, ressource, information, recherche ou possibilité qu'un utilisateur souhaite partager, découvrir ou concrétiser dans Vitala.

# 3. Philosophie

Vitala ne demande pas : « Créer une annonce »

Vitala demande :

- Que recherchez-vous ?
- De quoi avez-vous besoin ?
- Que souhaitez-vous partager ?
- Que souhaitez-vous réaliser ?
- Que souhaitez-vous proposer ?
L'utilisateur décrit librement son besoin. Le système aide ensuite à structurer l'opportunité.

# 4. Conditions préalables

Statut minimum requis : Membre enregistré L'utilisateur doit disposer d'un compte actif.

# 5. Déclenchement

L'utilisateur lance une création depuis :

- Home
- Flash
- Radar
- Bouton d'action principal
- Recommandation Vita
# 6. Saisie libre

L'utilisateur exprime son besoin avec ses propres mots. Exemple : « J'ai besoin d'une ménagère demain matin à Bonanjo pour préparer un repas de réunion. »

# 7. Analyse intelligente

Vita analyse automatiquement le contenu.

Identification automatique :

- Type d'opportunité
- Localisation
- Date
- Urgence
- Contexte
- Niveau de diffusion recommandé
# 8. Classification hybride

L'utilisateur n'est pas obligé de choisir une catégorie. Le moteur Vitala propose automatiquement une classification. Exemple : Entrée utilisateur : « J'ai besoin d'une ménagère demain matin à Bonanjo. » Classification proposée :

- Service
- Besoin local
- Mission ponctuelle
Vita demande éventuellement : « Confirmer ? » L'utilisateur peut :

- Accepter
- Modifier
- Ignorer
# 9. Informations obligatoires

Chaque opportunité doit contenir :

## Type d'opportunité

Exemples :

- Service

- Produit
- Mission
- Emploi
- Information
- Recommandation
- Partenariat
- Événement
- Autre
## Description

Description libre rédigée par l'utilisateur.

## Localisation

Au moins un élément :

- Position GPS
- Ville
- Quartier
- Zone
# 10. Informations recommandées

Les informations suivantes améliorent la qualité de diffusion :

- Date
- Heure
- Niveau d'urgence
- Rayon de diffusion
- Nombre maximal de manifestations d'intérêt
- Conditions particulières
# 11. Informations générées automatiquement

Le système crée automatiquement :

- Titre
- Auteur
- Statut
- Niveau de confiance
- Date de publication
- Horodatage

- Métadonnées
- Identifiants internes
# 12. Visibilité

Une opportunité peut utiliser trois modes de diffusion.

## Public

Diffusion selon les règles Vitala. Accessible aux profils pertinents.

## Diffusion contrôlée

L'auteur définit un nombre maximal de manifestations d'intérêt. Exemple : Maximum : 5 réponses Une fois le seuil atteint : L'opportunité n'accepte plus de nouvelles candidatures.

## Privé

Diffusion limitée. Exemples :

- Relations sélectionnées
- Profils spécifiques
- Réseau de confiance
- Zone restreinte
# 13. Contrôle automatique

Avant diffusion, l'opportunité passe par le Safety & Trust Filter Engine.

Vérifications :

- Anti-spam
- Anti-fraude
- Contenus interdits
- Cohérence
- Risque
- Niveau de confiance
# 14. Résultats possibles

## Validation immédiate

Publication directe.

## Validation renforcée

Demande d'informations complémentaires.

## Refus

Blocage de l'opportunité. Explication adaptée à l'utilisateur.

# 15. Diffusion

Après validation : L'opportunité est distribuée selon :

- Localisation
- Confiance
- Pertinence
- Centres d'intérêt
- Disponibilité
- Historique
# 16. Manifestations d'intérêt

Les utilisateurs intéressés peuvent se signaler.

Ils ne contactent pas directement l'auteur. Ils expriment simplement leur intérêt.

# 17. Gestion des candidatures

L'auteur consulte :

- Les profils intéressés
- Leur statut de confiance
- Leur historique utile
- Leurs recommandations éventuelles
L'auteur reste maître de la sélection.

# 18. Sélection

L'auteur choisit librement :

- Une personne
- Plusieurs personnes
- Aucune personne
Les autres utilisateurs sont automatiquement informés.

# 19. Passage à l'action

Une fois la sélection réalisée : L'opportunité entre en phase d'exécution. La mise en relation est activée.

# 20. Validation

Après réalisation : Les parties peuvent confirmer :

- Réalisé
- Partiellement réalisé
- Non réalisé

# 21. Création de confiance

Chaque résultat validé peut alimenter :

- Réputation
- Recommandations
- Historique
- Évolution du niveau de confiance
# 22. Cycle de vie officiel

Création ↓ Analyse automatique ↓ Diffusion ↓ Manifestations d'intérêt ↓ Sélection ↓ Action ↓ Validation ↓ Confiance

# 23. Principes UX

## Principe 1

Écrire avant de catégoriser.

## Principe 2

Conversation avant formulaire.

## Principe 3

Charge mentale minimale.

## Principe 4

Contrôle maximal pour l'auteur.

## Principe 5

Classification assistée par Vita.

## Principe 6

Diffusion intelligente basée sur la pertinence.

# 24. Critère de réussite

Le parcours est réussi lorsque : Utilisateur ↓ Exprime librement un besoin ↓ Vita structure automatiquement

↓ Publication validée ↓ Diffusion pertinente ↓ Manifestations d'intérêt qualifiées ↓ Sélection ↓ Action réalisée ↓ Confiance créée sans complexité inutile ni formulaire traditionnel.
