# VITALA-UJ-01-CONSULTANT-TO-MEMBER

**Document ID :** VITALA-UJ-01 **Titre :** Journey 1 — Consultant → Membre enregistré **Version :** 1.0 **Statut :** VALIDÉ **Dépendances :**

- VITALA-VISION-V1
- VITALA-PERSONAS-V1
- VITALA-TRUST-LEVELS-V1
# 1. Objectif

Transformer un visiteur inconnu en membre enregistré sans lui imposer une procédure d'inscription classique. L'utilisateur doit d'abord découvrir la valeur de Vitala avant de fournir des informations personnelles.

# 2. Point de départ

L'utilisateur ouvre Vitala pour la première fois. Statut : Consultant Le système ne possède aucune information sur lui.

# 3. Accueil Vitala

## Expérience d'accueil

Durée recommandée : 3 à 5 secondes maximum.

Objectif : Faire ressentir immédiatement la promesse de Vitala. Exemples de messages :

- Découvrez les opportunités autour de vous.
- Transformez vos besoins en solutions.
- Valorisez vos compétences.
- Développez votre confiance.
- Trouvez des personnes fiables grâce aux recommandations réelles.
L'animation disparaît automatiquement. Aucune interaction n'est obligatoire.

# 4. Home Consultant

Le consultant arrive sur une version spécifique de la Home. Cette Home est conçue pour informer, rassurer et susciter l'intérêt. Elle présente :

- La mission de Vitala.
- Les bénéfices principaux.
- Des exemples d'opportunités.
- Les fonctionnalités Flash.
- Les fonctionnalités Radar.
- Les fonctionnalités Veille.
- Les recommandations.
- Les histoires et cas d'usage réels.
# 5. Liberté d'exploration

Le consultant peut :

- Explorer librement.
- Consulter les contenus publics.
- Découvrir les fonctionnalités.
- Observer les opportunités visibles.
- Comprendre le fonctionnement général de la plateforme.
Aucune inscription n'est demandée. Aucun formulaire n'est affiché.

### Aucune interruption n'est imposée.

# 6. Première action importante

Le consultant décide volontairement d'effectuer une action. Exemples :

- Lancer un Radar.
- Ouvrir un Flash.
- Sauvegarder une opportunité.
- Suivre une veille.
- Répondre à une opportunité.
- Publier une opportunité.
Cette action devient le déclencheur naturel de la progression.

# 7. Intervention de Vita

Vita intervient uniquement lorsqu'une information doit être conservée ou lorsqu'une action nécessite une continuité. Exemple : « Bonjour 👋 Je peux garder cette découverte pour votre prochaine visite. Comment souhaitez-vous que je vous appelle ? »

# 8. Première information collectée

Information demandée : Prénom Exemple : Jean Cette information permet de personnaliser l'expérience.

# 9. Information de contact

Uniquement lorsque cela devient utile à l'action en cours. Informations acceptées :

- Téléphone
- Email
Exemple : « Où puis-je vous prévenir lorsqu'une opportunité vous concerne ? »

# 10. Création silencieuse du compte

Une fois les informations minimales obtenues :

- Prénom
- Téléphone ou Email
Le système crée automatiquement un compte. Aucune page :

- Inscription
- Créer un compte
- Bienvenue dans votre compte
n'est affichée. L'expérience doit rester naturelle.

# 11. Confirmation naturelle

Vita informe simplement : « Merci Jean. Je pourrai maintenant retrouver vos découvertes lors de votre prochaine visite. »

# 12. Résultat

Nouveau statut :

Membre enregistré Informations connues :

- Prénom
- Téléphone ou Email
# 13. Capacités obtenues

Le membre enregistré peut désormais :

- Publier des opportunités.
- Répondre à des opportunités.
- Utiliser Flash.
- Utiliser Radar.
- Utiliser Veille.
- Sauvegarder des découvertes.
- Recevoir des alertes.
- Participer à l'écosystème Vitala.
# 14. Contrôle de sécurité automatique

Toute publication passe automatiquement par : Safety & Trust Filter Engine Contrôles réalisés :

- Anti-spam.
- Anti-fraude.
- Analyse de cohérence.
- Détection de contenus interdits.
- Évaluation du niveau de confiance.
L'utilisateur ne voit jamais les mécanismes internes.

# 15. Principes UX

## Principe 1

Découverte avant inscription.

## Principe 2

Action avant identité.

## Principe 3

Chaque information demandée doit avoir une utilité compréhensible.

## Principe 4

Aucun formulaire long.

## Principe 5

L'utilisateur ne doit jamais avoir l'impression de créer un compte.

## Principe 6

Vita accompagne sans interrompre.

## Principe 7

La charge mentale doit rester minimale.

# 16. Critère de réussite

Le parcours est considéré comme réussi lorsque : Consultant ↓ Découverte ↓ Première action ↓ Premier échange avec Vita ↓ Membre enregistré

sans frustration, sans formulaire et sans abandon.
