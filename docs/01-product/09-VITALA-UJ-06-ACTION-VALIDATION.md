# 1. Objectif

Permettre à Vitala de confirmer qu'une opportunité a produit un résultat réel. La validation constitue le point de départ de la création de confiance. Sans validation, il n'existe aucune preuve que l'action a réellement eu lieu.

# 2. Philosophie

Vitala valorise les actions réelles. La confiance ne provient pas :

- des publications;
- des likes;
- des abonnés;
- de la popularité.
La confiance provient des résultats obtenus.

# 3. Définition

Une action validée est une opportunité ayant produit un résultat confirmé.

# 4. Déclenchement

La validation devient disponible lorsque :

- une sélection a été effectuée;
- une mise en relation a été créée;
- l'opportunité est considérée comme terminée ou exécutable.
# 5. Parties concernées

Une validation peut impliquer :

- Auteur de l'opportunité
- Participant sélectionné
Selon le contexte :

- plusieurs participants
- une organisation
- une entreprise
- une association
# 6. Validation progressive

La validation repose sur la participation des parties concernées. Exemple : Auteur ↓ Confirme ↓ Participant ↓

Confirme ↓ Validation complète

# 7. Résultats possibles

Chaque partie peut indiquer l'un des statuts suivants.

## Réalisé

Objectif atteint. Le besoin a été satisfait. L'action a été exécutée avec succès.

## Partiellement réalisé

Une partie du résultat attendu a été obtenue.

## Non réalisé

L'action n'a pas abouti.

## Annulé

L'action a été interrompue ou abandonnée avant exécution.

# 8. Commentaire facultatif

Chaque partie peut ajouter une explication. Exemples :

- Mission reportée.
- Indisponibilité.
- Changement de besoin.
- Problème technique.

- Conditions modifiées.
Le commentaire reste facultatif.

# 9. Validation complète

Une validation est considérée comme complète lorsque les parties concernées ont confirmé le résultat.

# 10. Validation partielle

Lorsque certaines confirmations sont encore attendues : Statut : Validation en attente

# 11. Désaccord

Les parties peuvent déclarer des résultats différents. Exemple : Auteur : Réalisé Participant : Non réalisé

Dans ce cas : Statut : Validation en désaccord

# 12. Neutralité du système

Vitala ne désigne jamais automatiquement un responsable.

Le système enregistre simplement :

- les déclarations;
- les preuves éventuelles;
- l'historique.
# 13. Gestion interne

Le moteur Trust & Safety peut analyser :

- incohérences répétées;
- comportements suspects;
- abus éventuels;
- fraudes potentielles.
Ces analyses restent internes.

# 14. Effets de la validation

Une validation enrichit :

- l'historique utilisateur;
- les preuves de confiance;
- les statistiques internes;
- les recommandations futures.
# 15. Aucun score public

Vitala ne montre jamais :

- note sur 5;
- score de réputation;
- classement.
Les résultats servent uniquement à construire la confiance.

# 16. Notifications

Les parties concernées reçoivent :

- Demande de validation.
- Validation reçue.
- Validation complétée.

- Désaccord détecté.
# 17. Historique

Chaque validation est enregistrée dans l'historique de l'opportunité. Exemples :

- Réalisé
- Partiellement réalisé
- Non réalisé
- Annulé
# 18. Préparation à la recommandation

Après une validation réussie : Vitala peut proposer : « Souhaitez-vous recommander cette personne ? » ou « Souhaitez-vous recommander cette organisation ? »

# 19. Préparation à la confiance

La validation constitue la base du moteur de confiance Vitala. Chaque validation contribue à construire :

- la crédibilité;
- la fiabilité;
- les recommandations;
- les niveaux de confiance.
# 20. Principes UX

## Principe 1

La validation doit être simple.

## Principe 2

Quelques secondes doivent suffire.

## Principe 3

Les résultats réels sont prioritaires.

## Principe 4

La neutralité est préservée.

## Principe 5

Aucune notation publique.

## Principe 6

La confiance se construit progressivement.

# 21. Critère de réussite

Le parcours est réussi lorsque : Opportunité ↓ Sélection ↓ Action réalisée ↓ Validation des parties ↓

Historique enrichi ↓ Base de confiance créée sans notation publique ni mécanisme de popularité.
