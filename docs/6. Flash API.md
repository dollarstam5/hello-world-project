API-CONTRACT-003 — Flash API

Version : V1

Statut : MVP

1. Mission

La Flash API est responsable de la création, de la gestion et de la diffusion des Flash au sein de Vitala.

Un Flash représente une intention exprimée par un utilisateur afin de déclencher une interaction avec la

communauté.

Le Flash constitue l'unité fondamentale de communication et de collaboration de la plateforme.

9. Sécurité

Seul le propriétaire peut modifier ou supprimer son Flash.

Les droits de consultation dépendent :

•

de la visibilité ;

•

des règles de confidentialité ;

•

des permissions de la plateforme.

Toutes les opérations sont journalisées.

10. Dépendances

La Flash API dépend de :

•

Auth API ;

•

Media API ;

•

Unified Digital Identity API (pour identifier l'auteur).

Elle ne dépend pas directement :

•

du Trust ;

•

du Radar ;

•

de la Veille ;

•

des Recommandations.

Les moteurs spécialisés exploitent les événements produits par le domaine Flash.

Le domaine Flash est conçu pour accueillir de nouveaux types d'intentions sans modification des

contrats fondamentaux.

De nouveaux modèles de Flash pourront être ajoutés tout en conservant les mêmes capacités métier.
