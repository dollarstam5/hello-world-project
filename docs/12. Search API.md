API-CONTRACT-009 — Search API

Version : V1

Statut : MVP

1. Mission

La Search API fournit une recherche unifiée à travers l'ensemble des domaines de Vitala.

Elle permet aux utilisateurs de retrouver rapidement les informations pertinentes sans connaître le

domaine qui les héberge.

La Search API orchestre la recherche.

Elle ne devient jamais propriétaire des données recherchées.

3. Responsabilités

La Search API est responsable de :

•

exécuter une recherche globale ;

•

appliquer les filtres ;

•

classer les résultats ;

•

agréger les réponses des domaines ;

•

retourner un format de réponse cohérent.

Elle ne modifie jamais les données recherchées.

4. Capacités

L'API permet notamment :

•

rechercher globalement ;

•

rechercher uniquement dans un domaine ;

•

filtrer les résultats ;

•

trier les résultats ;

•

rechercher par mots-clés ;

•

rechercher par catégories ;

•

rechercher selon différents critères (date, localisation, pertinence, etc.).

5. Objets recherchés

La Search API peut retourner des résultats provenant de :

•

Flash ;

•

Missions ;

•

Utilisateurs (UDI) ;

•

Recommandations autorisées ;

•

Opportunités détectées par le Radar ;

•

Éléments de Veille ;

•

Futurs domaines (Organisations, Projets, Marketplace…).

Chaque résultat indique son domaine d'origine.

6. Règles métier (Business Rules)

•

Chaque domaine reste propriétaire de ses données.

•

La Search API ne modifie jamais les ressources trouvées.

•

Les résultats respectent les règles de confidentialité.

•

Les résultats sont classés selon leur pertinence.

•

Les index de recherche peuvent être reconstruits sans modifier les contrats des domaines.

8. Validation

L'API valide notamment :

•

la cohérence des paramètres ;

•

les domaines autorisés ;

•

les droits d'accès ;

•

les filtres disponibles.

9. Sécurité

Toutes les recherches respectent :

•

l'authentification lorsque nécessaire ;

•

les autorisations ;

•

les paramètres de confidentialité ;

•

les politiques d'accès définies par chaque domaine.

Un résultat inaccessible n'est jamais exposé.

3

10. Dépendances

La Search API dépend de :

•

Auth API ;

•

Unified Digital Identity API ;

•

Flash API ;

•

Mission API ;

•

Trust API (si certains critères sont autorisés) ;

•

Radar API ;

•

Veille API ;

•

Recommendation API.

Elle dépend également du service ou de l'index de recherche utilisé par la plateforme.

11. Événements produits

La Search API publie notamment :

•

SearchPerformed

•

SearchSuggestionSelected

•

SearchResultOpened

•

SearchHistoryCleared

Ces événements peuvent être exploités afin d'améliorer la pertinence des recherches et des

recommandations.

12. Évolutions futures

La Search API pourra intégrer :

•

recherche sémantique ;

•

recherche conversationnelle ;

•

recherche multimodale (texte, image, document) ;

•

recherche assistée par intelligence artificielle ;

•

recherche fédérée avec des sources externes.

Ces évolutions conserveront les mêmes contrats fondamentaux.
