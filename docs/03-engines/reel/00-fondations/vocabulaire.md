# Vocabulaire fonctionnel

| Terme | Définition |
|---|---|
| Présence | État volontaire indiquant qu'un utilisateur est visible dans Réel. |
| Zone / rayon | Périmètre de proximité utilisé pour la découverte. |
| Statut / intention | Texte ou titre exprimant ce que l'utilisateur souhaite dans l'instant. |
| Profil | Informations consultables sur une personne. |
| Bip | Demande ou manifestation d'intérêt adressée à l'auteur d'une intention. |
| Acceptation | Décision de l'auteur d'accepter un bip. |
| Mise en relation | Relation fonctionnelle créée après acceptation. |
| Communication | Canal associé à une mise en relation ou action autorisée. |
| Clôture | Fin de la mise en relation, appliquée aux deux participants. |
| Trace technique | Métadonnées minimales nécessaires à la cohérence et à la traçabilité. |

**À confirmer :** définition UX et technique stable du « bip » : acteur émetteur, destinataire, états et événements.
