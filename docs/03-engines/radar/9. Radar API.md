API-CONTRACT-006 — Radar API

Version : V1

Statut : MVP

1. Mission

La Radar API expose les opportunités détectées automatiquement par le Radar Engine.

Son objectif est d'aider les utilisateurs à découvrir des personnes, des missions, des Flash et d'autres

éléments pertinents sans effectuer de recherche manuelle.

Le Radar fonctionne de manière proactive.

Le Radar Engine analyse les événements produits par les autres domaines afin de générer des

opportunités pertinentes.

1

3. Responsabilités

La Radar API est responsable de :

•

exposer les opportunités détectées ;

•

présenter leur niveau de pertinence ;

•

permettre leur consultation ;

•

gérer leur cycle de visibilité.

Elle ne crée jamais directement une opportunité.

Elle expose uniquement les résultats produits par le Radar Engine.

4. Capacités

L'API permet notamment :

•

consulter son Radar ;

•

consulter une opportunité détectée ;

•

masquer une opportunité ;

•

enregistrer une opportunité pour plus tard ;

•

signaler une opportunité non pertinente.

5. Objet métier

Radar Opportunity

Une Radar Opportunity représente une opportunité détectée automatiquement à partir des données de

la plateforme.

Elle peut concerner :

•

un Flash ;

•

une Mission ;

•

un utilisateur ;

•

une organisation (future évolution) ;

•

un projet (future évolution).

6. Règles métier (Business Rules)

•

Les opportunités sont exclusivement produites par le Radar Engine.

•

Aucune opportunité n'est créée directement via cette API.

•

Le niveau de pertinence est calculé par le Radar Engine.

2

•

Les opportunités respectent les règles de confidentialité et de visibilité.

7. Contrat REST

Endpoints principaux :

•

GET /radar

•

GET /radar/{id}

•

POST /radar/{id}/save

•

POST /radar/{id}/hide

•

POST /radar/{id}/report

8. Validation

L'API vérifie :

•

les droits d'accès ;

•

la visibilité des ressources ;

•

la disponibilité des opportunités ;

•

les permissions de l'utilisateur.

9. Sécurité

Toutes les opérations nécessitent une authentification.

Les opportunités exposées respectent les règles de confidentialité définies par leurs domaines

propriétaires.

10. Dépendances

La Radar API dépend :

•

du Radar Engine ;

•

de l'Auth API ;

•

de l'Unified Digital Identity API.

Elle consomme les données issues des domaines Flash, Mission et futurs domaines via le Radar Engine,

sans jamais en devenir propriétaire.
