API-CONTRACT-002 — Unified Digital Identity API

(Profile API)

Version : V1

Statut : MVP

1. Mission

La Unified Digital Identity API (UDI API) expose l'identité numérique officielle de l'utilisateur.

Elle constitue le point d'accès unique permettant aux interfaces (PWA, Flutter, partenaires) de consulter

et de mettre à jour les éléments de l'identité numérique autorisés.

Elle ne calcule aucune donnée métier.

Elle agrège les informations produites par les différents domaines de Vitala.

Dans l'interface utilisateur, cette API est présentée sous le nom Profil.

2. Position dans l'architecture

Cette API appartient à la couche des API Contracts.

Elle dialogue avec la couche d'agrégation UDI, qui construit l'identité numérique à partir des domaines

métier.

Chaîne de responsabilité :

Interface → UDI API → Unified Digital Identity → Business Domains

3. Responsabilités

L'UDI API est responsable de :

•

exposer l'identité numérique complète de l'utilisateur ;

•

permettre la mise à jour des informations dont l'utilisateur est propriétaire ;

•

exposer les différentes Views produites par les domaines ;

•

garantir une représentation cohérente de l'identité.

L'API permet notamment :

•

•

gérer les paramètres de confidentialité ;

•

consulter les différentes Views (Trust, Activity, Radar, Veille, Recommendation, Statistics).

7. Validation

L'API valide notamment :

•

les champs modifiables par l'utilisateur ;

•

les formats de données ;

•

les droits d'accès ;

•

la cohérence des mises à jour.

Les données produites par les moteurs ne peuvent jamais être modifiées via cette API.

8. Sécurité

L'accès est réservé à un utilisateur authentifié.

Chaque opération est soumise :

•

à l'authentification ;

•

aux autorisations ;

•

aux règles de confidentialité ;

•

à la journalisation des actions importantes.

•

•

CapabilitiesUpdated

•

IntentionsUpdated

•

PreferencesUpdated

•

PrivacyUpdated

Les Views sont mises à jour automatiquement lorsque leurs domaines producteurs évoluent.

11. Évolutions futures

L'architecture permet d'ajouter de nouveaux modules (Organization Identity, Project Identity,

Community Identity, etc.) sans modifier les contrats existants.

L'UDI API restera le point d'accès unique à toute identité numérique gérée par Vitala.
